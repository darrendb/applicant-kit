# applicant-kit
A toolkit for job seekers - turn online job postings into structured documents.

## Purpose
This project serves as a learning tool and a code portfolio. The modules here largely correspond to a domain or concept related to one or more subject areas covered by the curriculum for CCAR-F (Claude Certified Architect - Foundations) or PCAP (Certified Associate in Python Programming) certifications. This will demonstrate my recent hands-on explorations and capabilities.
